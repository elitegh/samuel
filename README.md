# CR7-Style Developer Portfolio

A premium, one-page portfolio built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS** using a CR7-inspired visual style for a software engineer profile.

## Features

- **Hero** — Full-viewport intro with bold typography and CTAs
- **Contact cards** — Card-based profile/contact grid
- **Experience timeline** — Horizontal scroll with company highlights
- **Achievements** — Animated stats counters
- **Iconic moments** — Alternating media + story layout
- **Brand partners** — Infinite marquee
- **Newsletter** — Stay-tuned signup (demo)
- **Responsive** — Mobile-first with smooth animations (Framer Motion)

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/data/content.ts` to change name, copy, images, experience entries, stats, and links. Replace Unsplash URLs with your own assets in `public/`.

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React icons
